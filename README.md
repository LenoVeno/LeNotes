# LeNotes

A simple terminal-based note-taking system written in Bash.

## About

LeNotes is a personal project created for learning Linux, Bash scripting and automation.

The goal of the project is to quickly create and manage notes directly from the terminal.

## Features

* Create notes from terminal
* Supports spaces in note names
* Opens notes in terminal editor
* Simple and lightweight

## Project Structure

notes/ - active notes

archive/ - archived notes

templates/ - note templates

scripts/ - project scripts

## Usage

Run:

./newnote.sh

Enter the note name and start writing.
